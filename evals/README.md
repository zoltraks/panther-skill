# Evals

## Purpose

> **Scope:** Index of the behavioral regression corpus under `evals/`
> **Key items:** schema, coverage

`evals/evals.json` holds behavioral regression prompts covering creation in all
languages, convention-preserving edits, reformatting, encodings, translations,
corrections, the update check, bare activation, and audits.

Run the prompts as behavioral evaluations after structural changes - they do not
replace independent review.
