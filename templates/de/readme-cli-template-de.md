# tool-name

Eine Zeile, die beschreibt, was das Werkzeug tut.

## Installation

```bash
Installationsbefehl
```

## Befehle

| Befehl  | Was er tut   |
|---------|--------------|
| `run`   | Führt es aus |
| `build` | Baut es      |

## Optionen

| Option      | Standard | Beschreibung          |
|-------------|----------|-----------------------|
| `--verbose` | false    | Ausführliche Ausgabe  |

## Beispiele

```bash
tool-name run --verbose
```
