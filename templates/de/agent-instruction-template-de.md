# Anweisungstitel

## Zweck

Was dieses Dokument anweist und welche Zielgruppen es bedient.

Für den menschlichen Leser: wie dieses Dokument als Referenz verwendet wird.

Für den KI-Coding-Agenten: welchen Abschnitt er wann ausführt.

## Anwendungsfälle

- Das Szenario, das dieses Dokument abdeckt, eines pro Zeile.

## Entscheidungspunkte

Vor Beginn stellt der Agent jede Pflichtfrage und wartet auf die Antwort.

**Fragename**

"Wörtliche Fragestellung, die der Agent dem Benutzer präsentiert?

- Erste Option - empfohlener Standard
- Zweite Option
- Der Benutzer kann eine andere Antwort angeben."

## Verfahren

Die Schritte, die der Agent für jedes Szenario ausführt.

1. Erste Stufe - was der Agent tut.
2. Zweite Stufe - was der Agent als Nächstes tut.

## Validierung

Bestätige vor dem Abschluss alle folgenden Punkte:

- [ ] Jedes erforderliche Artefakt existiert.
- [ ] Jede in diesem Dokument definierte Regel wird eingehalten.

## Beispielinhalt

```markdown
# Eingebettetes Gerüst

Eine kopierfertige Vorlage, die der Agent ausfüllt.
```
