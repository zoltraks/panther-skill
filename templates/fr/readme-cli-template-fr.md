# nom-outil

Une ligne qui décrit ce que l'outil fait.

## Installation

```bash
commande d'installation
```

## Commandes

| Commande | Ce qu'elle fait |
|----------|-----------------|
| `run`    | L'exécute       |
| `build`  | Le construit    |

## Options

| Option      | Défaut | Description      |
|-------------|--------|------------------|
| `--verbose` | false  | Sortie détaillée |

## Exemples

```bash
nom-outil run --verbose
```
