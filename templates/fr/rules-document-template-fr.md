# Titre des règles

## Objet

À quoi ces règles s'appliquent et qui doit les suivre.

## Sources de référence

- `FILE.md` - source de référence pour X.

## Règles générales

Formulez les règles en phrases impératives.

Nommez d'abord la règle, puis la justification quand celle-ci n'est pas évidente.

### Correct

```markdown
Exemple correct.
```

### Incorrect

```markdown
Exemple incorrect.
```

## Exceptions

Où les règles ne s'appliquent pas, le cas échéant.
