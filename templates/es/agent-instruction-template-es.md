# Título de la instrucción

## Propósito

Qué ordena este documento y qué destinatarios atiende.

Para el lector humano: cómo este documento sirve de referencia.

Para el agente de codificación IA: qué sección ejecuta y cuándo.

## Casos de uso

- El escenario que cubre este documento, uno por línea.

## Puntos de decisión

Antes de empezar, el agente plantea cada pregunta obligatoria y espera la respuesta.

**Nombre de la pregunta**

"Pregunta literal que el agente presenta al usuario?

- Primera opción - valor por defecto recomendado
- Segunda opción
- El usuario puede dar otra respuesta."

## Procedimientos

Los pasos que el agente ejecuta para cada escenario.

1. Primer paso - qué hace el agente.
2. Segundo paso - qué hace a continuación el agente.
