# nombre-herramienta

Una línea que describe qué hace la herramienta.

## Instalación

```bash
comando de instalación
```

## Comandos

| Comando | Qué hace     |
|---------|--------------|
| `run`   | Lo ejecuta   |
| `build` | Lo construye |

## Opciones

| Opción      | Por defecto | Descripción      |
|-------------|-------------|------------------|
| `--verbose` | false       | Salida detallada |

## Ejemplos

```bash
nombre-herramienta run --verbose
```
