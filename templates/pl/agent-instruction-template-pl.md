# Tytuł instrukcji

## Przeznaczenie

Co instruuje ten dokument i jakim odbiorcom służy.

Dla czytelnika: jak korzystać z tego dokumentu jako z odniesienia.

Dla agenta AI: którą sekcję wykonać i kiedy.

## Przypadki użycia

- Scenariusz, który obejmuje ten dokument, po jednym w wierszu.

## Punkty decyzyjne

Przed rozpoczęciem agent zadaje każde obowiązkowe pytanie i czeka na odpowiedź.

**Nazwa pytania**

"Dosłowna treść pytania, którą agent przedstawia użytkownikowi?

- Pierwsza opcja - zalecana wartość domyślna
- Druga opcja
- Pozwól użytkownikowi podać inną odpowiedź."

## Procedury

Kroki, które agent wykonuje dla każdego scenariusza.

1. Pierwszy etap - co robi agent.
2. Drugi etap - co robi agent dalej.

## Weryfikacja

Przed zakończeniem potwierdź wszystkie poniższe:

- [ ] Każdy wymagany artefakt istnieje.
- [ ] Każda zasada zdefiniowana w tym dokumencie jest przestrzegana.

## Przykład zawartości

```markdown
# Osadzony szkielet

Gotowy do skopiowania szablon, który agent wypełnia.
```
