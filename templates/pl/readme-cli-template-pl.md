# nazwa-narzędzia

Jedno zdanie opisujące, co narzędzie robi.

## Instalacja

```bash
polecenie instalacji
```

## Polecenia

| Polecenie | Co robi   |
|-----------|-----------|
| `run`     | Uruchamia |
| `build`   | Buduje    |

## Opcje

| Opcja       | Domyślnie | Opis             |
|-------------|-----------|------------------|
| `--verbose` | false     | Szczegóły działa |

## Przykłady

```bash
nazwa-narzędzia run --verbose
```
