# Współpraca przy <Projekt>

Dziękujemy za zainteresowanie współpracą przy <Projekt>.

Ten dokument wyjaśnia, jak zgłaszać problemy, przygotować środowisko i przesyłać zmiany.

## Sposoby współpracy

- Zgłaszaj błędy i prośby o funkcje przez system zgłoszeń.
- Ulepszaj dokumentację.
- Przesyłaj zmiany kodu przez pull requesty.

## Zgłaszanie problemów

Przed otwarciem nowego zgłoszenia przeszukaj istniejące.

Zgłaszaj jeden problem w jednym zgłoszeniu i podaj wersję, środowisko, kroki reprodukcji
oraz oczekiwane i rzeczywiste zachowanie.

## Konfiguracja środowiska

```bash
git clone <adres-repozytorium>
cd <projekt>
<polecenie instalacji>
<polecenie sprawdzenia>
```

Przed otwarciem pull requesta uruchom kontrole projektu.

## Pull requesty

- Każdy pull request dotyczy jednej zmiany.
- Stosuj konwencję komunikatów commitów przyjętą w projekcie.
- Dodaj lub zaktualizuj testy przy zmianie zachowania.
- Utrzymuj kontrole CI w stanie poprawnym.

## Wkład wspomagany AI

Ujawnij, gdy zgłoszenie lub zmiana powstała z pomocą AI.

Osobiście zweryfikuj każde ustalenie wygenerowane przez AI przed zgłoszeniem - nie wklejaj
surowego wyniku AI do zgłoszenia ani pull requesta.

Musisz rozumieć przesyłany kod i brać za niego odpowiedzialność - zmiany wspomagane AI
spełniają te same wymagania stylu, testów i licencji co każdy inny wkład.
