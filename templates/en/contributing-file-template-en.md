# Contributing to <Project>

Thank you for your interest in contributing to <Project>.

This document explains how to report issues, set up the project, and submit changes.

## Ways To Contribute

- Report bugs and request features through the issue tracker.
- Improve documentation.
- Submit code changes through pull requests.

## Reporting Issues

Search the existing issues before opening a new one.

File one issue per problem and include the version, environment, reproducible steps, and the
expected versus actual behavior.

## Development Setup

```bash
git clone <repository-url>
cd <project>
<install command>
<check command>
```

Run the project checks before opening a pull request.

## Pull Requests

- Keep each pull request focused on a single change.
- Follow the project's commit message convention.
- Add or update tests for behavior changes.
- Keep the CI checks green.

## AI-Assisted Contributions

Disclose when a report or change was produced with AI assistance.

Verify every AI-generated finding yourself before reporting it - do not paste raw AI output
into an issue or pull request.

You must understand and own the code you submit - AI-assisted changes follow the same style,
testing, and licensing requirements as any other contribution.
